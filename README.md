# 🛍️ Customer Shopping Behavior Analysis

> **End-to-end Customer Shopping Behavior Analysis using SQL, Python (Pandas), and Power BI to uncover purchasing patterns, sales trends, customer preferences, and actionable business insights.**

--------------------------------------------------------------------------------------------------------------------------------------------------------------
## 📌 Project Overview

Understanding customer purchasing behavior is essential for making data-driven business decisions. This project analyzes a retail shopping dataset to identify customer demographics, purchasing trends, revenue drivers, and shopping preferences.

The project follows a complete Data Analytics workflow:

- Data Cleaning & Preprocessing using **Python**
- Data Storage & Business Queries using **MySQL**
- Interactive Dashboard Development using **Power BI**
- Business Insights & Recommendations

--------------------------------------------------------------------------------------------------------------------------------------------------------------

## 🎯 Objectives

- Clean and preprocess raw customer shopping data.
- Perform exploratory data analysis (EDA).
- Write SQL queries to solve real business problems.
- Build an interactive Power BI dashboard.
- Generate actionable business insights for decision-making.

# 🧹 Data Cleaning & Preprocessing

The dataset was cleaned and transformed using **Python (Pandas)**.

### Data Cleaning

- Checked dataset information
- Generated descriptive statistics
- Handled missing values
- Renamed columns
- Standardized column names
- Removed unnecessary columns

### Feature Engineering

Created new features including:

- Age Group
- Purchase Frequency (Days)

### Data Transformation

- Converted purchase frequency into numerical values
- Filled missing review ratings using category median
- Dropped redundant columns
- Prepared cleaned dataset for SQL analysis
